# LLM Fullstack

Zach Erdley

## What this project is

This is a project where I implement and serve an llm from scratch. I follow Karpathy's Zero to Hero for the code to train a mimiGPT and subsequently containerize an application that streams the output tokens of the miniGPT. My goal with this project is to get into more breadth of both the ML architecture for llms and the infrastructure required to serve llm output at scale.
